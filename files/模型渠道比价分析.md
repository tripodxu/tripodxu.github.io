## 2. 口径与换算假设（重要，先读）

统一单位：**元 / 1M tokens**，分三档计价：未命中缓存输入、命中缓存输入、输出。

**综合参考价** = `0.2 × 未命中输入 + 0.7 × 命中缓存 + 0.1 × 输出`
（模拟 agent/编程助手负载：长上下文大部分命中缓存、少量新输入、少量输出。换权重不会改变渠道排序，只会整体缩放。）

**相对牌价** = 该渠道综合参考价 ÷ 该模型官方按量牌价（DeepSeek 取高峰价为基准；GPT/Muse 无官方价，取聚合站标价为基准）。

各订阅体系的换算方法：

| 体系 | 换算方法 | 校验 / 风险 |
| :--- | :--- | :--- |
| **小米 Token Plan** | 表中费率是 **Credits/token**（方向已核实），1M tokens 消耗 = 费率×1e6 Credit；等效价 = 费率×1e6 ×（月费 ÷ Credit 额度） | **已用官方 API 海外定价 $0.435/$0.87 校准**：1 Credit ≈ $1.45e-9 ≈ ¥1.04e-8，Plan 等效价 = 牌价的 **0.77–0.94×**。官方 FAQ 另有「1 Token = 1 Credit，Pro 2x、长上下文 4x」的扣减口径，长上下文为主的负载建议控制台实测 |
| **智谱 Plan** | 积分 =（输入×In + 缓存×Cache + 输出×Out)/10000，即 1M tokens = 100×系数 积分；积分单价 = 月费 ÷（每周积分 × 52/12） | **已核实：周积分 7 天刷新、周期结束不累积** —— 当周用不满则实际单价高于本文（本文按月均 4.33 周连续计量）。抵扣系数 Flash（In 2.3）约为 GLM-5.3（In 6.9）的 1/3，**Plan 内跑 Flash 单任务更省积分** |
| **StepFun Plan** | 1 元 = 1,000,000 Credit，即 Plan 名义面值 = Credit 数 ÷ 1e6 元；折扣倍数 = 月费 ÷ 名义面值 | **已核实：1M Credit = ¥1、Credit 月末清零不结转**；不适用开放平台按充值金额的 RPM/TPM 阶梯限速，但协议保留并发任务数 / 并发工具调用数 / 上下文长度等限制。名义面值须当月用完，档位按当月实际消耗选 |
| **Command Code / OpenCode** | 美元标价 × 7.2（汇率） ×（月费 ÷ 包含额度） | **已核实：Go 是唯一不提供 API 的计划（调用返回 `upgrade_required`）；GOAT / Pro / Max / Team 均提供 API 且用量计入计划额度**。「Monthly credits」列是**单模型月度上限**（名义美元） |
| 汇率 | 1 USD = 7.2 CNY | 7.1–7.3 区间内排序不变 |

**所有订阅价均假设额度 100% 用满**。用不满时按比例变贵（例：GOAT $10 只用掉 $35 名义额度，倍数就从 0.143 升到 0.286）。

## 6. 风险与待核实事项

**已核实（官方文档 / FAQ 确认）**

1. **Command Code Go 的 API 边界 —— 确认**：Go 是唯一不提供 API 的计划，调用返回 `upgrade_required`；**GOAT、Pro、Max、Team 均提供 API**，用量计入计划额度。原「CC GOAT」结论**不需要**顺延到 Pro。
2. **小米 Token Plan 的 Credit 口径 —— 确认并校准**：官方 FAQ 为「1 Token = 1 Credit（Pro 模型 2x、长上下文 4x）」；价目表按 Credits/token 计的方向正确。已用官方 API 海外定价 **$0.435/$0.87** 校准：1 Credit ≈ $1.45e-9 ≈ ¥1.04e-8，Plan 等效价 = 牌价的 **0.77–0.94×**（Max 0.77× 最深、Lite 0.94× 最浅）。
3. **StepFun Plan 规则 —— 确认**：1M Credit = ¥1；**Credit 月末清零、不结转**；不适用开放平台按充值金额的 RPM/TPM 阶梯限速，**但协议保留并发任务数、并发工具调用数、上下文长度等限制**，不能理解为「完全无限速」。
4. **智谱 Plan —— 确认**：周积分 **7 天刷新、周期结束不累积**（当周用不满则实际单价高于本文）；抵扣系数 GLM-5.3-Flash（In 2.3）远低于 GLM-5.3（In 6.9），**Plan 内跑 Flash 单任务更省积分**（修正此前「买 Plan 就用 GLM-5.3」的单一说法）。
5. **单模型月度上限 —— 确认**：CC 的 Go/GOAT 以美元价值定义限额、各模型额度不同（$15–$67 名义/月）；OpenCode Go 机制类似。突破后需购买按量付费额度或等待周期重置；CC 的 5 小时 / 每周窗口限额也是隐性吞吐上限。

**仍需留意**
