三句话总结：

  1. 订阅折扣是最大杠杆。Command Code / OpenCode 的「月费 ÷ 包含额度」在 0.10×–0.25× 之间，但 $1 的 Go 档不提供 API，API 用户实际从 GOAT（0.143×）起步。
  2. 官方 Plan 的折扣力度天差地别。StepFun 折到 1%–12% ＞ 智谱 11%–78% ＞ 小米 Token Plan 仅 77%–94%，基本要靠夜间 0.8× 和首购 88 折才有看头。
  3. 渠道分工明确，没有全网通吃。StepFun 系只认官方 Plan；GLM / MiMo / DeepSeek 认聚合订阅；FlashX 只认官方 API；GPT / Muse 系只能在 Command Code Pro 及以上拿。

使用前提与风险提示

  • 所有「订阅价」都假设额度 100% 用满，用不满按比例变贵（例如 GOAT $10 只用掉 $35 名义额度，倍数就从 0.143 涨到 0.286）。
  • 单模型月度限额普遍只有 $15–$20 名义额度，重度使用会被卡；突破后回落按量价或改走官方 Plan / 拉新抵扣金。
  • 小米拉新 300 抵扣金有效期 40 天、先到先扣，不可抵 Token Plan、不可提现；StepFun Credit 月末清零；智谱积分 7 天刷新不累积。
  • DeepSeek 工作日 9–12、14–18 为双倍高峰价，能排程的批处理流量尽量放到空闲时段（半价）。
  • 海鲜市场收购 StepFun 首登资格存在账号归属 / 封号 / 实名风险；TierFlow 为全新平台，建议先小额验证。
  • 汇率按 1 USD = 7.2 CNY；7.1–7.3 区间内各渠道排序不变。
